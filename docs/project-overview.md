# StayNest Project Overview

## Project name

StayNest

## Purpose

StayNest is a free, local-first hotel management system designed to help hotels manage daily operations without depending on a hosted service or constant internet access.

## Technology stack

- **Frontend:** React, Vite, and Tailwind CSS
- **Backend:** Django and Django REST Framework
- **Database:** MySQL Community
- **Authentication:** JWT
- **Chatbot:** Local Ollama with a deterministic fallback

## Main roles

- Admin
- Manager
- Receptionist
- Housekeeping
- Customer

## Planned modules

- **Dashboard:** Role-based summaries of occupancy, bookings, revenue, tasks, and operational alerts.
- **Reservations:** Create, modify, cancel, and track room reservations, availability, check-in, and check-out.
- **Rooms and property management:** Maintain rooms, room types, rates, amenities, and room status.
- **Guest management:** Store customer profiles, stay history, preferences, and contact details.
- **Billing and payments:** Prepare invoices, record payments, manage charges, and support refunds or adjustments.
- **Housekeeping:** Assign cleaning tasks and track room readiness, maintenance issues, and status changes.
- **Staff and access control:** Manage users, roles, permissions, and activity relevant to hotel operations.
- **Reports:** Provide operational and financial reports for management decision-making.
- **Chatbot assistance:** Offer local, privacy-friendly assistance through Ollama, with deterministic fallback responses when the local model is unavailable.
